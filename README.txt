دعوة تخرج ياسمين حلمي - ملفات GitHub Pages

محتويات ZIP:
- index.html : صفحة الدعوة والتفاعلات
- cover.png : صورة الغلاف
- details.png : صورة تفاصيل الحفل
- abdelhaleem22.mp3 : الموسيقى المرفقة

رفع الموقع:
1. فك ضغط ملف ZIP.
2. ارفع الملفات الأربعة الموجودة داخل المجلد مباشرةً إلى جذر مستودع GitHub.
3. افتح Settings > Pages، واختر النشر من الفرع main والمجلد /(root)، ثم Save.
4. افتح رابط GitHub Pages بعد انتهاء النشر.

وظائف الأزرار:
- موقع الجامعة: يفتح بحث موقع كلية الإعلام بجامعة القاهرة في Google Maps.
- تأكيد الحضور: يطلب الاسم ويفتح واتساب برسالة تأكيد جاهزة؛ يجب الضغط على إرسال داخل واتساب.
- مشاركة الدعوة: يفتح نافذة المشاركة في الهاتف/المتصفح إذا كانت مدعومة.
- صور الدعوة: يفتح نافذة معاينة للصورة.
- فيديو الحفل: يوضح أن ملف فيديو لم يُرفق بعد.
- نسخ الرابط: ينسخ رابط الصفحة المنشورة.

الموسيقى:
تحاول الصفحة تشغيل الأغنية تلقائيًا عند الفتح، وتظل مشغلة أثناء الانتقال/التمرير إلى تفاصيل الدعوة لأنها صفحة واحدة. المتصفحات غالبًا تمنع التشغيل التلقائي بالصوت؛ لذلك يوجد زر واضح لتشغيلها يدويًا عند منع التشغيل التلقائي.

مهم:
زر تأكيد الحضور يفتح واتساب برسالة جاهزة لكنه لا يرسلها تلقائيًا ولا يسجل الرد في قاعدة بيانات. لا يوجد رقم منظّم مرفق، لذا يفتح واتساب لاختيار جهة الاتصال.
